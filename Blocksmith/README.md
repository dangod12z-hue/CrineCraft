# Blocksmith (Unity 2022.3 LTS)
Open in Unity 2022.3 LTS. Modular Minecraft-like sandbox with Redstone upgrades.

- Scripts live at `/Scripts` (per spec). Unity sees them via `Assets/Scripts` symlink.
- First open auto-creates a default scene via an Editor script (`FirstOpenSetup`).
- Mods live in `Assets/StreamingAssets/Mods`.
- Blueprints live in `Assets/StreamingAssets/Blueprints`.
